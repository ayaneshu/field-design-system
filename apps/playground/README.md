# playground

Expo app for previewing Field Design System tokens, typography, and icons on device or web.

```sh
pnpm install
pnpm playground          # from repo root
# or:
pnpm --filter playground start
```

Tabs:

- **Colors** — every base palette, every shade
- **Typography** — every text style with the right Noontree weight
- **Icons** — every icon shipped in `@field-ds/icons`
